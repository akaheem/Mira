{# Absolute paths, not request.url_for('static', ...). These URLs are a deployment contract: Vercel promotes the StaticFiles mount to the CDN, so the stylesheet and the fonts are served from there and never invoke the Python function. url_for on a *named mount* has changed behaviour across Starlette versions -- some produce /static//css/styles.css for a leading-slash `path` -- and a wrong URL here fails as an unstyled page, which is a silent failure in exactly the component this product is built around. The paths are fixed, so they are written as fixed paths. The font files are declared inside styles.css and are referenced from there, so only the serif needs a preload here: it sets the first heading on every page, and it is 25KB rather than 48KB. Inter falls back to the system sans for the instant before it swaps in, which is close enough that the swap is not visible. #} Skip to main content
